# デプロイ後の確認方法

- **`curl` で本番 HTML を見ても、クライアントレンダリングされた中身は分からない。** `apps/web` は Vite の MPA で、各ページの静的 HTML には `<div id="root">` のような空のマウント先しか入っておらず、実際の DOM は React が実行時に描画する。`curl https://fudoki.dev/pipeline/` の出力に特定の文言があるか無いかで「反映された/されていない」を判定すると、静的 HTML 側にたまたま同じ文字列があるだけで誤って一致・不一致を報告することがある。
  - Why: SSR していないため、ビルド後の HTML は description・OGP・JSON-LD などの `<head>` メタ情報だけを持ち、`<body>` の実コンテンツはブラウザが JS を実行するまで存在しない。
  - How to apply: デプロイ後にヘッダー構成・ナビの有無・特定要素の表示/非表示など、レンダリング結果を確認したいときは実ブラウザ（ego-browser 等）で開いて DOM を見る。`curl` は HTTP ステータス・リダイレクト・メタタグの確認にとどめる。
