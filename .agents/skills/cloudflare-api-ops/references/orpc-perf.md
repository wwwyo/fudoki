# oRPC のパフォーマンス系オプションのハマりどころ

- **oRPC v1（1.15 系）には出力バリデーション（zod でのレスポンス検証）を無効化するオプションが無い。** `disableOutputValidation` 相当の機能は v2 で追加されたもので、v1 のドキュメント・型を探しても見つからない（存在しないものを探して時間を溶かした）。
  - Why: v1 は「型安全な契約に対して常に検証する」ことを前提にしており、検証コストを個別に切る口を持たない。
  - How to apply: Cloudflare Workers 無料プラン（CPU 10ms/リクエスト）のような CPU 予算が厳しい環境で、大きな配列を返すエンドポイントの zod 検証コストが問題になったら、v1 のままでは「無効化」では対処できない。レスポンスを chunk 分割してリクエストあたりの検証対象を減らす、または v2 への移行を検討する。
