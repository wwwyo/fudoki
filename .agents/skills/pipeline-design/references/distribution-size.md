# 配布物（正本・派生 CSV）のサイズ膨張

正本・派生（`data/packages/` 配下の FDP CSV）は、コードと名称の分離・識別子の付与・COFOG 列の追加により、**原典 CSV より大幅に大きくなる**。

- 実測（三鷹市 令和6年度、歳出 5,613行）: 原典 CSV 816KB に対し、正本+派生 CSV は 6.3MB（約8倍）
- 62団体×1年度へ外挿: 約390MB。62団体×9年度: **約3.5GB**
- gzip 圧縮で 534KB（原典比 1/1.5、非圧縮の正本+派生比 1/12）に収まる。FDP は CSV のまま `compression` を持たせられるため、標準適合を崩さずに縮められる
- Parquet だと 517KB とさらに小さいが、FDP 系ツールが Parquet を読める保証は未検証

**How to apply**: 全団体・全年度の正本・派生を git に commit する設計を検討するときは、CSV のまま置くと東京62団体規模で GB 級になることを前提にする。「原典は置かない・成果物は git に残す」という方針（AGENTS.md 方針3）を保つなら、圧縮形式（gzip 等）を既定にするか、配布先を検討する。年度を絞ることで容量を抑える案は、横断比較というこの PJ の目的そのものを削ることになるため避ける。
