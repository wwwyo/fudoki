# dev サーバの起動先

`.claude/launch.json` はこのセッションから書き込みができない（編集を試みて拒否された）。

- ダッシュボード（パイプライン可視化画面）の dev サーバは `web/` 配下にあり、`bun run dev` で起動する（`package.json` のスクリプト経由）
- `.claude/launch.json` に別名のプレビュー設定（例: `survey`）が残っていることがあるが、これは③会議録レイヤの調査ビューアなど別の画面を指している場合があるので、名前だけで判断せず中身（どの `web/*.html` を配信するか）を確認してから使う

**How to apply**: dev サーバを起動する前に `package.json` の `dev` スクリプトの有無を先に確認する。無ければ `.claude/launch.json` を読むだけにして、書き換えが必要になったらユーザーに直してもらう。
