# kotonoha（言の葉）

日本の地方議会の会議録を [Popolo](https://www.popoloproject.com/) スキーマに正規化して配布するオープンデータプロジェクト。

会議録は公開されているのに機械可読ではなく、横断も経年比較もできない。予算がどう決まり何に使われたかの**過程**は、そこにしか残らないのに。

- 生成データはオープンデータとして本リポジトリで公開
- コードは MIT
- MCP サーバとしても配布し、AI エージェントが直接読める形にする

名前は古今和歌集の仮名序「よろづの言の葉とぞなれりける」から。

## Getting Started

前提: [mise](https://mise.jdx.dev/)

```bash
mise install
bun install
```
