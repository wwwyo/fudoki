# E案の色比較

2026-10-04。形・Noto Sans JP 700・字間は採用したE案を保持し、ライト背景で4色を比較する。

比較ページは `../logo-colors.html`、一覧画像は `../logo-colors.png`。`colors.json` に候補の値を記録する。各ディレクトリの SVG は比較用。

実画面はローカル検証画面 `/pipeline/`、表示幅は撮影時の `product-state.json` に記録。文字を高さ40pxで1px下へ補正。ブラウザ内でSVGを各候補に、`--primary` を共通のオレンジ #C1553A に一時差し替え、同じ領域を撮影した。`context.jpg` は同じ矩形の抜粋、`product.jpg` は画面全体。
