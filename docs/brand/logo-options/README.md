# 風土記のロゴ候補（2026-10-04）

比較した5案の記録。2026-10-04にE案を採用した。比較ページは `../logo-options.html`。全案でマーク単体・ワードマーク単体・横組みと明暗の SVG を用意した。

- A / 角印: 「風」を白抜き。Noto Sans JP 800、字幅を96%、字間4 / 4。
- B / 和綴じ: 冊子の内側に綴じ糸を配置。Noto Sans JP 600、字間6 / 6。輪状の綴じ具はリングノートに見えたため修正した。
- C / 四つの枠: 菱形を対称に配置。Noto Sans JP 700、字間3.5 / 4.5。
- D / 土地の字: 「土」のマークと、直線を基調に描いた三文字。既成フォントを使わない。
- E / 元の短冊・単色: 元の五本の短冊と基準線を寸法・角丸・配置まで保持し、全体を緑一色にした。Noto Sans JP 700、字間3 / 4。

A〜C・E の字間はフォントの送りではなく、見える輪郭の間隔。字体の原寸は32、ワードマークの viewBox は高さ40。D は線幅2.4の独自字形。

各案のマーク24px・横組み40pxを、ローカル検証画面 `/pipeline/` に表示して比較ページに記録した。表示幅はA〜Dが619px、Eが1116px（図の部分を抜粋）。比較ページに16pxのマークと明暗の使用例も掲載した。元の画面の内容・数値・レイアウトはそのまま使用している。

比較ページは320 / 375 / 414 / 768pxで横への溢れがないことを確認した。

日本らしさ、名前とのつながり、小サイズの読みやすさ、文字の重さで判断する。A は小さな印の字形が密、B は出版物寄り、C は名前との直接のつながりが薄く、D は字形の癖が強い。

SVG の再生成（repo root から）:

```sh
mise exec -- uv run --no-project --exclude-newer 2026-09-26 --with fonttools==4.66.0 --with brotli==1.2.0 python docs/brand/logo-options/build.py
```

字母は既存の `@fontsource-variable/noto-sans-jp` 5.3.0（OFL-1.1）。`contact.svg` は一覧用の配置、`../logo-options.png` はその表示用画像。
