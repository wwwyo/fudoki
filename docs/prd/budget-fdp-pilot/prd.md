# budget-fdp-pilot

## Problem

自治体の予算は公開されているが、機械では読めない。

三鷹市の令和6年度に「いじめ問題対策協議会関係費」がいくら付いたかを知るには、資料を開いて人が探すしかない。
他市と比べるなら他市の資料も開き、科目体系の違いを人が頭の中で吸収することになる。
市をまたぐ比較も、年をまたぐ比較も、事実上できない。

可視化そのものは、もう不足していない。
デジタル庁の「地方財政（市町村ごと）に関するダッシュボード」は市区町村を対象とし、類似団体や近隣自治体との比較機能まで備えている。

欠けているのは粒度と横断性の2つである。
ダッシュボードが扱うのは地方財政状況調査にもとづく決算で、分類は目的別と性質別にとどまり、事業単位に届かない。
そして事業単位の資料は各自治体が個別の形式で公開しており、同じ軸で並べられない。

粒度を上げるだけでも足りない。
英国は500ポンドを超える全取引の公表を法で義務づけているが、「コンサルタントにいくら使ったか」を答えるには今も情報公開請求が要る。
100を超える自治体が、自分たちでも算出できないと回答した。
横断できる分類軸を持たない金額データは、明細が細かくても問いに答えられない。

したがって必要なのは、事業単位まで構造化したうえで、横断できる分類軸を持たせることである。

そして fudoki は、配布用に変換したデータである**正本**をまだ1件も持っていない。
権利条件を判定し、データを取得できることまでは確認したが、変換はまだ動いていない。
標準への割り当てが実際に成立するかは、机上では確かめられない。

## Overview

三鷹市の歳出予算データを、財政データを記述する仕様である **Fiscal Data Package（FDP）** に変換し、金額を政府支出の機能別分類である **COFOG** へ割り当てて公開する。

fudoki の最終的な対象には実際の使途も含むが、本 PRD の対象は予算額に限る。

1団体に絞るのは、変換設計を実データで確定してから他の自治体へ展開するためである。
複数団体を同時に扱うと、どの差異が自治体固有の事情によるもので、どの差異が自治体に共通する構造によるものかを、順序立てて切り分けられない。

対象を三鷹市にしたのは、令和6年度の938件の事項がすべて名称を持つからである。
款から細々節までの全階層がコードと名称の両方を持ち、平成28年度から令和6年度までのファイルが公開されている。
比較対象として検討した狛江市は執行額を持つ利点があるが、事業も科目も数値コードだけで名称がなく、何に使ったかを読めない。

必須の成果物は令和6年度とする。
平成28年度から令和5年度までは、収録可能かどうかの互換性調査を対象とし、収録そのものは条件としない。

### Goals

- 三鷹市の令和6年度予算を、機械可読な標準形式で誰でも取得できる状態にする。
  歳出と歳入の双方を収録する（歳入に分類軸は付けない）
- 款から細々節までの階層を保ち、事項の単位まで辿れるようにする
- 金額を COFOG へ割り当て、割り当てが成立する粒度と、成立しない範囲を明らかにする
- 変換結果が正しいことを、三鷹市の公表資料によって外部から確認できるようにする
- 他自治体へ展開するときに、再利用の候補、三鷹市で観測した固有要素、2団体目まで一般性を判定できない要素を区別して記録する

### Non-Goals

- 執行額の取り込み。
  三鷹市の当該データは予算のみを持つ。
  執行額は別の団体を追加する段階で扱う。
- 歳入への分類軸の適用。
  COFOG は支出の機能別分類であり歳入には使えないため、GFSM の収入分類など別の軸を立てる必要がある。
  歳入そのものは収録する（Goals を見ること）。
- 歳入を主語にした検証。
  歳入の階層は目の下が節と細節で、事項にあたる区分を持たないため、事業単位の配分という本 PRD の問いに答えない。
  歳入について行うのは、歳出との合計の一致を確かめる交差検算だけとする。
- 平成28年度から令和5年度までの収録。
  互換性調査までを対象とする。
- 2団体目以降への展開。
  「再利用可能と判明した」という結論は後続の PRD へ送る。
- 調達データおよび会議録との突合。
  データを厚くする方向は将来展望であり、本 PRD の存在価値には含めない。
  ただし接続キーが成立することは検証する（Acceptance Criteria「外部データと突合できる形になっている」）。
- 案件の早期発見や課題マッチングといった用途の実証。
  いずれも将来展望であり、本 PRD は配布するデータそのものを成果とする。
- 閲覧用の画面、API、MCP サーバの提供。
  配布形式はファイルにとどめる。
- COFOG のグループ以下への割り当て。
  ディビジョンまでを対象とする。
- 他国との比較の実施。
  比較の候補となる分類軸を作るところまでとする。
- 2団体目の追加時間の測定。
  後続の PRD で追跡する。
- ハッカソン提出物としての構成。
  提出のスコープは本 PRD とは別に決める。

## Glossary

- **款、項、目、節**：地方自治法にもとづく歳出予算の科目区分。
  款が最も粗く、節へ向かうほど細かい。
- **細々節**：三鷹市が節の下に置く科目区分。
- **事項**：三鷹市が目の下に置く区分。
  令和6年度で938件あり、すべて名称を持つ。
  本 PRD では事項を、事業を表す候補として扱う。
  自治体横断の「事業」概念として確定するのは2団体目以降とする。
- **Fiscal Data Package（FDP）**：財政データを記述するための仕様。
  現行は 1.0.0（`fiscal.datapackage.org`）。
  列の意味を fiscal concepts（ColumnTypes）で与える。
- **Budget Standard Taxonomy**：FDP のうち予算データ向けの列型を定めたもの。
  COFOG と GFSM の列型を含む。
- **budget phase**：予算の段階を表す列型。
  `phase:id` と `phase:label` で構成する。
- **COFOG**：政府支出の機能別分類。
  Budget Standard Taxonomy では部門、グループ、クラスの3階層として定義されている。
- **正本**：fudoki が配布する変換後のデータ。
  取得した生データと区別する。
- **原典**：三鷹市が公開する変換前の元データ。

## Acceptance Criteria

すべての受け入れ条件に共通する判定方法を先に固定する。

- [ ] リポジトリだけを受け取った第三者が、固定された検証手順とその実行結果を用いて、以下のすべてを再判定できる

### 年度ごとの原典と収録範囲が記録されている

- [ ] 各年度について、原典の URL、取得日時、原典ファイルのハッシュが記録されている
- [ ] 年度ごとに、列構成、行数、含まれる会計、金額の単位、budget phase が記録されている
- [ ] 年度によって会計の範囲が異なることが記録されている（令和2年度以降のリソースには「下水道事業会計除く」の注記があり、平成28年度から令和元年度にはない）
- [ ] 令和5年度以前の各年度について、令和6年度と互換かどうかと、その判定根拠が記録されている

### パイプラインが正しく動いたことを人が判定できる

- [ ] 各段について、入力と出力の件数、その差分、1行がどう変わったかの実例、検査結果が報告として出ている
- [ ] Load の入力と出力で行数の差分が0である。0でない場合は原因が示されている
- [ ] 正本には fudoki の判断が含まれず、COFOG の割り当ては派生側にある

### 令和6年度が FDP として配布されている

- [ ] 三鷹市の令和6年度予算が FDP として、認証なしで誰でも取得できる
- [ ] 歳出と歳入の双方が同一のパッケージに収録され、金額ごとに支出と収入の別が記述されている
- [ ] 会計ごとに、歳入の合計が歳出の合計と一致する。これは三鷹市の令和6年度当初予算について確認済みの条件付き検算であり、決算や補正差分では成立しないことが明記されている
- [ ] 準拠する FDP の仕様版と、Budget Standard Taxonomy を使っていることが明記されている
- [ ] 列の意味づけに Budget Standard Taxonomy の ColumnTypes を使っており、独自に定義した列型があれば一覧化されている
- [ ] 各行が年度を持ち、原典のファイル名に依存せずに年度を特定できる
- [ ] 金額が円へ正規化されて `value` に入り、原典の値と単位（千円）が別の列に残っている
- [ ] 各金額の budget phase が、原典または三鷹市の公表資料にもとづいて決められている
- [ ] budget phase を確認できない場合、その年度を収録しない
- [ ] 原典の URL、取得日時、CC BY のライセンスと帰属表示が成果物に含まれている

### 予算の階層が壊れずに保たれている

- [ ] 会計、款、項、目、事項、節、細々節が、それぞれ独立した切り口として取り出せる
- [ ] 原典の全行が、欠落も重複もなく変換後のデータに多重集合として対応する
- [ ] 行の識別子の衝突が0件である。衝突がある場合は正本を生成しない
- [ ] 任意の細々節から親の款まで一意に辿れる
- [ ] コードが同じでも親が異なる要素が、混同されずに区別される
- [ ] コードと名称を分離した場合、原典のセルの表記を復元できる
- [ ] 事項名（例：「いじめ問題対策協議会関係費」）で絞り込み、その金額を取り出せる

### 三鷹市の公表値と一致している

- [ ] 突合に使う公表資料が、資料名、URL、年度、該当箇所、対象の会計、予算の段階、単位とともに作業前に一つへ固定されている（三鷹市「令和6年度 施政方針・予算概要」を想定する）
- [ ] 令和6年度一般会計の合計が、その公表資料の値と一致する
- [ ] 令和6年度一般会計の款別集計が、いずれも公表値と一致する
- [ ] 突合に、前年度比からの逆算値、検索結果の要約、原典を再集計した値のいずれも使っていない
- [ ] 一致しない場合、次の区分にもとづいて判定されている
  - 変換による欠落または重複が原因の場合は不合格とする
  - 会計の範囲や予算の段階の違いが原因の場合は、差額と対象行を再計算できる形で示せば許容する
  - 原典自体の矛盾が原因の場合は、成果物に警告を付ける

### COFOG への割り当ての成立範囲が分かる

- [ ] 使用する COFOG の版が COFOG 1999 に固定され、ディビジョンの値域が `01` から `10` であることと、コード表の取得元が記録されている
- [ ] COFOG を格納する列型に Budget Standard Taxonomy のもの（`functional-classification:cofog:division:code` 等）を使っている。日本の予算科目から COFOG への対応そのものは仕様側に存在しないため、fudoki 固有の判断としてパイプライン報告に残す
- [ ] 一つの金額が、分類の軸（割当済み・分類不能・対象外）と連結の軸（保持・消去）の状態をそれぞれ一つ持ち、一度だけ計上されている
- [ ] 分類不能と対象外が区別されている（COFOG の対象は経費と非金融資産への純投資であり、公債の元金償還のような金融取引は対象外）
- [ ] 消去する行に、連結の範囲と相手側の行の識別子が記録されている
- [ ] 分類不能と対象外の行では COFOG のコードが空である
- [ ] 全状態の合計が原典の合計と一致し、かつ割当済みと分類不能の合計が適格母集団の合計と一致する。いずれも年度・会計・予算段階・direction ごとに確かめる
- [ ] 款の単位で割り当てが決まらない金額について、項、目、事項のどの単位まで下げれば決まるかが記録されている
- [ ] どの単位まで下げても複数の機能へ分かれ、配分の根拠がない金額は、未分類として理由とともに記録されている
- [ ] 割り当ての根拠が、金額の単位ごとに読める形で残っている
- [ ] 款ごとの割当先・状態・根拠が、パイプライン報告に出ている

### 外部データと突合できる形になっている

- [ ] 全国地方公共団体コード、会計年度、会計、階層の各要素が、機械的に識別できる
- [ ] 突合の相手とするデータセットと接続キーが、作業前に一つへ固定されている
- [ ] 団体コードと年度をキーとして、そのデータセットと実際に突合できる

### 再生成でき、展開時に何を検証すべきかが分かる

- [ ] 正本の各版に、取得時点の原典の URL、取得日時、SHA-256 が紐づいている
- [ ] 原典が取得できる間は、同じ原典から正本を再生成でき、結果が一致する
- [ ] 一致の判定規則が作業前に一つへ固定されている（生成日時などの可変部分を除いたハッシュの一致、または正規化後のレコード集合と集計値の一致のいずれか）
- [ ] 原典が取得できなくなった場合に、その時点の正本を正として残す方針が明記されている（原典そのものは保全しない）
- [ ] 変換の各要素が、再利用の候補、三鷹市で観測した固有要素、2団体目まで一般性を判定できない要素のいずれかに分類されている

## Success Metrics

- **原典行の保持率**：原典の行が変換後に対応づく割合。
  100パーセントを満たすこと。
- **COFOG 割り当ての合計保存**：割り当て後の合計が割り当て前の合計と一致すること。
- **割り当て根拠の記録率**：割り当て結果と未分類のいずれについても根拠が残っている割合。
  100パーセントを満たすこと。
- **展開時の再検証項目の記録率**：三鷹市固有または一般性未判定と分類した要素のうち、2団体目で何を確かめるかが記録されている割合。
  100パーセントを満たすこと。
