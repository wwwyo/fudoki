# pipeline-view prototype（上下分割・採用案）

> [!NOTE]
> このディレクトリは `.agent/prototypes/pipeline-view/` からのコピー。`assets/`（原典 PDF `chiyoda-r8kaikeiyosan.pdf` と頁画像 217 枚、計 29MB）は**意図的に除外**してある。自治体の資料の写しを repo に載せると再配布にあたるため（再配布許可を確認済みなのは62団体中2団体）。再生成するには、千代田区の公開ページから当該 PDF を取得し、39–255 頁を PNG に描画して `assets/pdf-131016-p<頁>.png` として置く（頁画像が無くても PDF ビューア以外の機能はすべて動く）。


`/pipeline/<団体コード>/` を「1団体の配布物が正しいか」確かめるローカル検証ツールに作り直すための試作。上下レイアウト3サブ案（固定分割 / 一体スクロール / 縮む帯）を比較し、**固定分割**を採用したものだけを残してある。比較で棄却した2案は戻せる決定なので記録しない。

## 開き方

`index.html` をブラウザで開く（`file://` で動く。データは `data.js`、PDF ページ画像は `assets/` に埋め込み済み）。

- 団体の切替: 左上バー。年度切替: 見出しのセレクタ。どちらも URL（`?j=` `?y=`）に残る
- 図の**線を押す**とその組（入力→出力）が選択され I/O が開く。**ノードを押す**と出入りする組の候補が出る（1本なら即選択）
- 図はズーム（ホイール・＋/－/fit/1x）とパン（ドラッグ）に対応。境目の帯をドラッグすると上下の比率を変えられる
- I/O の行は双方向で対応する（同じ番号のバッジ）。千代田区の 原典→取り込み では左に PDF の実ページ（文字を選択できる。行を押すと PDF 上の該当箇所が強調、PDF 上の語を押すと行が選ばれる）

## レイアウト（採用案: 分割）

画面を上下2ペインに固定分割。上の図・下の I/O がそれぞれ独立にスクロールし（図ではパンが相当）、ページ自体はスクロールしない。境目をドラッグで比率を変えられる。

棄却した案:
- **一体（flow）** — 1枚のページとして縦に流れ、図が sticky 残留し選択で自動スクロール
- **帯（peek）** — 選択で図が上部の帯（ミニマップ）に縮み、I/O が画面を占める

## データ

- `data.js`: `apps/web/public/pipeline.json` の 131016・132195 分 + `data/fudoki.duckdb` から引いた各ノードの行サンプル（`source_row` 1–10、年度・direction 別）+ pkg は `data/budget/datapackages/<code>/*.csv` を直接読み（dbt view が相対パス参照のため）
- `assets/chiyoda-r8kaikeiyosan.pdf` + `assets/pdf-131016-p*.png`: provenance の `request_url` から取得した原典 PDF と頁画像。描画範囲は **39–255 頁**（`sources.toml` の `[statement."131016:2026".pages]` 宣言＝歳入 42–145・歳出 146–251 に、目次/総括と次節の先頭を前後数頁足したもの）。行→頁内位置の対応は pdfplumber の単語座標で 事業名/内訳名＋金額 を検索して求めた（`pdf-131016.json`。`hits` が行→bbox、`pages` に全描画頁の単語座標）。PDF ビューアはページ送り付きで、行を選ぶとその頁へ自動で移動する
