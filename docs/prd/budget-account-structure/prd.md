# 会計構造を core に組み込む

関連 PRD: [budget-fdp-pilot](../budget-fdp-pilot/prd.md)

## Problem

自治体の帳簿は一般会計・特別会計・公営企業会計に分かれ、款項目の体系は**会計ごとに異なる**。

fudoki の科目正規化（`account_names.csv` の `master_kan_code`/`master_kan_name` 等の `master_*` 列）は、一般会計の法定区分表への写像しか持たない。特別会計の行は狛江・三鷹とも master が全行空で、一般会計体系への誤写像ではなく**写像対象にすら含まれていない**。このため特別会計どうしの横断比較は款レベルでも成立しない —— 「国保にいくら使っているか」を団体間で比べる問いに答えられない。

しかも特別会計の款は会計固有の事業費科目であり、同名の款が別物を指す（国保会計の「総務費」≠一般会計の「総務費」）。一意なのは (会計, 款, 項, 目) であり、一般会計マスタへ畳むことは構造上できない。**会計種別ごとの科目マスタ**が要る。

さらに3つの問題がある。

- **会計名の揺れ**: 「介護保険特別会計」と「介護保険事業特別会計」は同じ制度の別表記で、fund の正規化がないと横断できない
- **繰出金の二重計上**: 狛江の一般会計民生費に節=繰出金が32億超あり、受け側の介護保険会計の給付（72.5億）も同じ COFOG division 10 に入る。`cofog_consolidation` は全行 retained で、**全 fund を素朴に合算すると同じ金が繰出と給付で二度計上される**（普通会計フレームで畳む集計では起きない —— 受け側の支出がその集計対象外のため）
- **外部検証の不在**: 現在の突合は団体自身の公表資料との比較で、解析が壊れたときの独立した判定相手がない

## 導出

Story の「他の街や他の年と同じ物差しで比べる」には特別会計が共通軸に乗ることと繰出の二重計上が無いことが前提で、「数字が怪しいと思ったときに確かめる」には原典と独立した外部集計が要る —— 本 PRD はこの2つの前提を core に組み込む。

## Overview

主課題は特別会計の科目正規化（会計種別ごとの科目マスタと fund の名寄せ）。
連結消去・外部統計との突合・収録範囲の確認は、それぞれ「集計の正しさ」
「解析の検証」「収録の記録」という独立した要件として併記する。

### Goals

- 特別会計の款項目を、**会計種別ごとの科目マスタ**で正規化する。
  一般会計側の `master_kind`（map / addition / historical）＋ `master_basis`（根拠文）
  の形をそのまま流用する
- 法定3会計（国保・介護・後期高齢者）から共通マスタを組む。
  写像先は推測せず、e-Stat の会計別調査表（46表 国保事業勘定、51表 介護保険事業勘定 等）
  と地方自治法施行規則の区分表から逆引きする
- fund 名を canonical な制度名・事業種別に名寄せする。**対象は収録済みの全 fund**
  （独自会計は科目マスタの整備対象外だが、名寄せは対象）。
  canonical は法律の語彙を借りる（法定会計→介護保険法3条等の制度名、
  独自会計→地方公営企業法施行令46条の事業種別）
- 節=繰出金の行を連結消去し、全会計連結の集計で「移転を除いた純支出」を取れるようにする
- 総務省統計（e-Stat 地方財政状況調査）を決算側の突合相手として使う。
  (団体, fund_label) → 部門区分の辞書は突合の際に同時に組む
- 狛江の公共下水道特別会計が 2023 決算歳出に無い件を確認し、収録範囲を記録する

### Non-Goals

- **公営企業会計の収録**。款項目節を持たない別体系（収益的収支・資本的収支＋勘定科目）で、
  東京の市町村はほぼ該当なし。方針の決定と記録は本 PRD の AC に含めるが、
  収録の実装は別の検討とする
- **行の属性としての部門区分の常設**。部門は会計の性質なので fund から導出でき、
  突合の時点で (団体, fund_label) → 部門の辞書を組めば足りる
- **独自会計（下水道・駐車場等）の款項目マスタ整備**。法定3会計で形を確定してから
- **一般会計マスタ（既存の `master_*` 写像）の変更**
- **配布物を総務省統計の区分に寄せること**。突合は検査用途であり、
  配布形式は原典の構造を保持する

## Glossary

- **一般会計・特別会計**：帳簿上の会計区分。特別会計は地方自治法209条2項で条例設置が原則、
  法定で義務づけられるものがある（介護保険法3条2項等）
- **普通会計**：総務省の統計用の仮想区分 = 全会計 − 公営事業会計。帳簿には存在しない
- **公営事業会計**：公営企業会計＋収益事業会計＋社会保険・共済系
  （国保・介護・後期高齢者・農業共済・交通災害共済）。調査はされるが普通会計には入らない
- **公営企業会計**：地方公営企業法の適用事業を企業会計（発生主義・複式簿記、
  収益的収支・資本的収支）で経理する会計。款項目節を持たない
- **法定3会計**：国保・介護保険・後期高齢者医療。設置が法律で義務づけられ、
  款の構造がほぼ共通
- **部門区分**：会計が普通会計相当か公営事業会計相当かの属性。(団体, fund_label) ごとの判定。
  境界は名称ではなく実態（狛江の駐車場の例）
- **連結消去**：会計間の内部移動（繰出金/繰入金）を合算時に両側で消す操作。
  企業会計の連結決算で親子間取引を相殺するのと同じ発想。
  **消すかどうかは集計の枠組み依存**で、普通会計フレームでは残す（総務省も残している）
- **会計固有款**：特別会計の款項目は一般会計の法定区分と別体系。
  一意なのは (会計, 款, 項, 目)

## 調査で確かめたこと

総務省「市町村別決算状況調」（地方財政状況調査）の団体別カード
（令和6年度分: https://www.soumu.go.jp/main_content/001063970.pdf 、
令和5年度分は `https://www.soumu.go.jp/iken/zaisei/r05_shichouson.html` に Excel あり）
を調べた過程で分かったこと。確認済みの事実と推定・未解決のものを区別して記す
（後者は「らしい」「推定」「要確認」と明記）。

### 総務省統計の粒度と使い道

- カードの歳出は**目的別（款相当）× 性質別の集計まで**。項・目・節・事業名は無い
  → fudoki の原典にはならない。ただし決算側の突合相手（全団体・全年度・同一様式）と、
  団体属性（財政力指数・実質収支比率・職員数・人口）のマスタとしては有用
- PDF をパースする必要は無い。**e-Stat「地方財政状況調査 市町村分 調査表」に
  統計表が CSV/API で出ている**（表番号07「歳出内訳及び財源内訳」等。会計別表もある）

### 普通会計の定義（実測で訂正）

- 普通会計 = **全会計 − 公営事業会計**。公営事業会計 =
  公営企業会計（地方公営企業法適用）＋ 収益事業会計 ＋
  **国保・介護保険・後期高齢者医療・農業共済・交通災害共済の社会保険・共済系**
  （根拠: 総務省準拠の調査要領例・地方財政白書の「一般行政部門とそれ以外の部門」表現。
  社会保険系は別表の指標として集計される）
- 検証（狛江・令和5年度決算）: カード歳出総額 34,434,964千円 vs
  fudoki 一般会計（執行済額）34,489,740千円 → 差 54,776千円（0.16%、
  執行済額と決算額の phase 差の範囲）。公債費は 1,555,406千円で**完全一致**
- 歳出総額に国保（77.6億）・介護（73.6億）・後期高齢者（23.3億）は**含まれない**。
  衛生費が 26.5億のままなので自明（含まれれば100億超になる）
- 狛江の**駐車場事業特別会計は普通会計に含まれない**と読むのが数字と整合する
  （足すと差は 108,317千円に開く。収益事業側=公営事業会計と推定。
  境界は名称ではなく事業の実態で決まる）
- **繰出金は差し引かれていない**。目的別に「諸支出金」の款があり繰出はそこに入り、
  性質別にも「繰出金」行がある。受け側（国保等）の支出が集計対象外なので
  普通会計フレームでは二重計上にならず、消す必要がそもそも無い

### 特別会計の科目体系

- **款項目は会計固有**。三鷹市の例: 国保会計の款 = 総務費・保険給付費・納付金・保健事業費…。
  **同名の款（「総務費」）でも一般会計の総務費とは別物**。一意なのは (会計, 款, 項, 目)
- 現状 `account_names.csv` の `master_*` 列は**一般会計分しか埋まっていない**
  （狛江・三鷹とも特別会計行は全て空）。**一般会計体系への誤写像ではなく、
  そもそも写像対象に含まれていない**。特別会計どうしの横断は款レベルでも今はできない
- 法定3会計（国保・介護・後期高齢者）は**設置が法律で義務づけ**られている
  （介護保険法3条2項等）。科目自体は法定ではないが、制度と国への報告様式
  （国保事業報告・介護保険事業状況報告）が事実上の足並みを作り、款名はかなり似通う。
  ただし揺れはある（「介護保険特別会計」vs「介護保険事業特別会計」、国保の款数も
  狛江7 vs 三鷹6）
- **公営企業会計は款項目節を持たない**（収益的収支・資本的収支＋勘定科目）。
  別統計（公営企業決算統計）になる。東京の市町村はほぼ該当なし（水道は都営）

### COFOG と繰出金

- 特別会計は COFOG に素直に乗る（会計が単一機能）。狛江で実装済み:
  介護→10、国保・後期高齢者→07、下水道→05、駐車場→04、いずれも会計単位ルール
- **同じ division に一般会計と特別会計が混じるのは仕様通り**（機能の軸は会計を区切らない）。
  狛江2023: div10 = 一般会計146.7億 + 介護会計72.5億
- **ただし繰出金の二重計上が未処理**: 狛江一般会計の民生費内に節=「繰出金」が32億超
  （一般会計→国保・介護への繰出）。`cofog_consolidation` は全行 retained で
  eliminated が0 → **現パッケージの集計は二重計上を含む**。
  一般会計繰出（民生費→10）と受け側支出（国保→07）で違う division に二重計上される
  パターンまである
- 救い: 「繰出金」は法定の性質科目（節）なので `setsu` で機械的に拾える。
  スキーマの `cofog_counterpart_fund` は消去の相手側を記録する設計済み
- 「特別会計が自立しているか」は**歳入側で測れる構造**（revenue.csv が会計別で、
  一般会計繰入金が別科目に分かれる）。ただし現金主義なので償却込みの真の採算は
  公営企業会計でしか出せない

### その他の発見

- 狛江の**公共下水道特別会計が 2023 executed の歳出に出てこない**
  （他年・他フェーズにはある。収録範囲の確認が要る）
- 総務省統計と fudoki の科目が完全に同じ原典由来であることは公債費の一致で証明済み

## Acceptance Criteria

### 特別会計の科目が会計種別ごとのマスタで正規化されている

- [ ] 法定3会計（国保・介護・後期高齢者）の共通款項目マスタが存在し、写像先の区分が推測ではなく e-Stat の会計別調査表（46表・51表等）と地方自治法施行規則の区分表から逆引きされている
- [ ] 特別会計の行でマスタ写像が埋まり、一般会計側と同じ `master_kind`（map / addition / historical）＋ `master_basis`（根拠文）の形で記録されている
- [ ] 同名の款が会計をまたいで別物として区別される（国保会計の「総務費」が一般会計の総務費マスタに写像されない）
- [ ] マスタに対応しない科目は unmapped として残り、根拠を持たない写像で埋められていない

### fund が制度・事業の単位で名寄せされている

- [ ] 「介護保険特別会計」と「介護保険事業特別会計」のような表記揺れが同一 canonical に正規化されている
- [ ] canonical の語彙が法定の制度名・事業種別に由来することが記録されている
- [ ] 「介護サービス事業特別会計」と「介護保険事業特別会計」のような名字の似た別制度が別 canonical に分かれている
- [ ] 名寄せの基準が制度の同一性であり、文字列類似で寄せていない

### 繰出金の連結消去が機能している

- [ ] 消去対象は「全会計連結で相手会計も集計に含まれる繰出」に限定され、節=繰出金は消去候補の特定方法として定義されている
- [ ] 相手会計の特定方法と、繰出額と相手会計側の繰入額の対応を検証する手順が定義されている
- [ ] 相手会計を特定できない繰出金の扱い（retained のまま理由付き等）が決められている
- [ ] 消去対象の行が `cofog_consolidation=eliminated` で記録され、`cofog_counterpart_fund` に相手会計が入る
- [ ] 全会計連結の集計で繰出金が二度計上されず、「移転を除いた純支出」が取れる
- [ ] 消去が行の固定属性ではなく集計ポリシーであることが明記されている —— 普通会計フレーム（突合用の畳み方）では総務省統計と同じく retained のまま残る

### 総務省統計との突合が成立する

- [ ] (団体, fund_label) → 部門区分の辞書があり、狛江の駐車場のような境界例の判定根拠が記録されている
- [ ] 比較対象の区分対応（統計の目的別款区分 ↔ fudoki 側の款マスタ）と揃える条件（会計範囲・年度・予算段階・単位）が作業前に固定されている
- [ ] fudoki 側を普通会計フレームで畳んだ歳出が、e-Stat「地方財政状況調査」の同区分の値と款レベルで比較できる
- [ ] 不一致時の判定区分（解析のバグ / 調査票への記入振替差 / 予算段階の差）が作業前に固定されている
- [ ] PDF をパースせず、e-Stat の機械可読な統計表を使っている

### 収録範囲の確認と記録

- [ ] 狛江の公共下水道特別会計が 2023 決算歳出に無い原因（原典の収録範囲か取り込み漏れか）が確認され、団体メモに記録されている

### 公営企業会計の方針が記録されている

- [ ] 公営企業会計を配布物に含めるかの方針（対象外宣言または別変換器の将来検討）が、東京市町村にほぼ該当が無い事実とともに決定・記録されている

### 誤読の罠が配布物に記録されている

- [ ] 部門の混在（普通会計相当と公営事業会計の素朴合算は意味が変わる）
- [ ] 会計間繰出の二重計上（繰出金は行として残る）
- [ ] 同名款が別物であること（特別会計内の「総務費」は一般会計の総務費ではない）
- [ ] 同じ事業でも団体ごとに会計形態が違うこと（下水道: 特別会計 vs 公営企業会計 vs 一般会計内）

## Success Metrics

配布物は git リポジトリの CSV であり利用計測の機構を持たないため、コアアクションの成立条件をデータ品質として数える（pipeline-verification-view と同じ置き換え）。分母は収録済み団体の配布物とする。

- コアアクション: 特別会計を含む歳出を、団体をまたいで共通の科目軸・COFOG 軸で比較する。また数字が怪しいときに外部統計と突合する
- 期待頻度 (cycle): 月次（Story の「団体をまたいで、または年をまたいで比べる」に一致）
- 数える対象: コアアクションの成立条件。法定3会計に属する科目行の写像率（unmapped の残りは理由付き）、消去対象繰出金行の適用率（100%）、収録済み全 fund の名寄せ率（canonical 不明が0件）、突合対象の款の説明付き一致率（一致または差分原因が説明できる割合）
- 主指標: 「国保・介護の支出を複数団体で比較」「全会計連結で二重計上なしの合計を取る」「総務省統計との款レベル突合」の3つの問いが収録団体で成立すること
