# 会計ごとの意味を保って団体間で比べる

関連 PRD: [財政データの構築](../budget-fdp-pilot/prd.md)

## Problem

一般会計と特別会計の同名科目は、同じ支出目的を示すとは限らない。制度の異なる会計を合算したり、繰出金を二重計上したりすると、自治体間の比較を誤る。会計の意味・科目の対応根拠・連結の条件をデータとともに確認できる必要がある。

## 導出

Storyの「団体をまたいで、または年をまたいで比べる」と「原典と合っているか・注意点を確かめる」を支える。

## Overview

会計名を制度・事業単位で名寄せし、特別会計の款・項を専用の共通科目へ対応付ける。会計間移転は両側の額と相手会計を確認した宣言だけを連結消去の対象とする。外部統計との照合は、参照値を採用した団体・年度・会計だけを検証する。

### Goals

- 会計の制度・部門と共通科目の根拠を保つ。
- 連結時の二重計上と、相手不明の移転を区別する。
- 参照統計との一致・既知の差・未解決の差を区別する。

### Non-Goals

- 特別会計の目の共通分類、公営企業会計の収録。
- 未確認の科目・移転・外部参照値の推定。
- 配布インフラや公開検索の実装。

## Acceptance Criteria

- [x] 収録会計の制度・部門・共通名が定まり、根拠を保持している。似た名称の別制度を混ぜない。
- [x] 特別会計の科目は専用の款・項へ対応し、対応しない科目は未対応として残る。
- [x] 確認した会計間移転だけが相手会計付きの連結消去対象となり、両側の金額が釣り合う。相手不明は保持する。
- [x] 採用した外部参照値と同じ会計・年度・段階・単位で照合し、未解決の差も検査結果と注意点に残る。

現在の固定入力に対する再検証と検査の証拠は [検証記録](../../monorepo-migration.md) にまとめる。提供モデルは [財政データの設計](../fiscal-records/design-doc.md)、宣言は `pipeline/dbt/seeds/fiscal/` にある。

## Success Metrics

- コアアクション: 特別会計を含む支出を比較し、疑わしい値を外部統計と照合する。
- 期待頻度: 月次。
- 数える対象: 収録済みの会計・科目・確認済み移転と採用済み参照値。
- 主指標: 会計の共通名が不明な行0件、確認した移転の適用漏れ0件。科目の未対応・照合の未解決件数を隠さない。

## 残る制約

- **目の共通マスタは組んでいない。** 款は調査票の勘定科目（52表・63表・64表・94表）で
  事実上共通、項は調査票の内訳列と帳簿で共通する語彙から canonical として定義した。
  目は団体の帳簿構造に依存しすぎて共通の比較軸が組めず対象外。
  款・項レベルの横断比較が成り立てば PRD の問い（「国保にいくら使っているか」）には答えられる
- **三鷹市・他団体・2018〜2022 の状況調突合は未収録。** `soumu_reference.csv` は
  狛江の 2023 決算分（futsu-kaikei と法定3会計）だけ。参照値は増やせるが、
  参照値が無い団体・年度は突合が行われない（skip ではなく参照無しとして扱う）
- **狛江の後期高齢者医療の納付金に 8 億円超の差分が残る**（帳簿 2,188,750,528 円 vs
  94表 1,355,124 千円）。広域連合への納付を帳簿と調査票が別の科目に載せている可能性が
  高いが要因は確定していない — `unresolved` として記録し、テストは差分を見落とさない
- **三鷹市の会計間移転のうち受け側が単一項に畳めないもの・狛江で対を組めない移転は
  retained のまま**（狛江メモに列挙）
- **独自会計の款・項の写像は部分的。** 介護サービス事業は 64 表の勘定科目で全写像。
  駐車場は決算資料の款別表で款が写像済み（2021年度以降）。下水道は歳入款7
  （繰入金）のみ写像 — 閉会計で款名の出所が無い残りは未写像のまま
