# monorepo 移行の検証記録

2026-10-01。設計 PR [#38](https://github.com/wwwyo/fudoki/pull/38) はマージ済み。実装の完了をこの記録の途中結果だけから判断しない。

2026-10-03 に配布・検索のインフラ設計を後段へ戻した。この文書には ingestion〜marts とローカル検証に関係する過去の確認結果を残す。配布向けのコード削除後に実行した検証は、下の「配布処理を外した後の検証」に記録する。

## 確認できたこと

- ingestion・dbt・FDP・報告・ローカル検証画面を `pipeline/`、共有する純粋なデータ規則を `packages/`、slides を root に移した。
- 全36入力の33種類の原典 CSV/PDF を回収し、既存の証跡の SHA-256 と一致した。原典の欠落は0。固定入力のローカル復元で build した。
- [ADR 0012](adr/0012-git-input-provenance.md) により採用した証跡36件・59,999 bytesを ingestion 配下の Git ファイルへ変更した。正規 lock の固定は原典・表の遠隔保管を検証してから行う。
- 固定入力のバックアップから空の別キャッシュへ全オブジェクトを復元し、33種類の原典のハッシュを照合した。macOS のネットワーク拒否 sandbox 内でも全量 build と再 build が成功した。
- ローカル view の実画面で、狛江市2023決算の原典 CSV と取り込み表の行2が同時に選択されることを確認した。千代田区2026予算では、表の行4から PDF 45頁の該当行へ移動し、PDF の行5の文字から表の行5を選択できた。

これらは当時の検証結果であり、現在の ingestion〜marts の完成を保証するものではない。歳出の節マスタ・事業×節への集約・下位内訳の現在の状態は [財政データの設計](prd/fiscal-records/design-doc.md) に残す。

## 配布処理を外した後の検証（2026-10-03）

- `pipeline:build` を dbt の変換・検査と marts の CSV 生成までに整理した。固定入力36件・原典33種類をローカルの移行用 lock から復元し、5団体の build と再構築が成功した。dbt はモデル・seed 156件、検査88件の計244件が成功し、再構築した全 CSV のハッシュが一致した。
- Bun 57件、Python 12件、全 workspace の型チェックと import・binding 境界の検査が成功した。
- web・API・docs の Worker dry-run build は成功し、データ binding がない。ローカル Worker に GET・POST・OPTIONS を送った27条件で HTTP 500 と `Cache-Control: no-store` を確認した。API の `/mcp` も含む。
- ローカル view の狛江市2023決算を実ブラウザで表示し、系統・行の表が描画されること、公開分析へのリンクがないことを確認した。marts の列説明と CSV・warehouse の行データ応答も確認した。

これはローカルでの検証である。正規 lock の採用、非公開 R2 への転送・復元、hosted CI、公開 Worker のデプロイは行っていない。補正等の実資料の収録・対応確認は未完了であり、パイプライン全体の完成とは区別する。
