# 団体別の内容版へ直接取り込み、反映済みの行を提供する

D1 の全体構築版への全明細の複製を廃止し、自治体別の内容版へ直接取り込む。未変更の団体と R2 の `packageId` は再利用する。取り込み途中の明細と団体ごとの反映時点の差を許容するため、全体の公開一覧と公開切替は設けない。

## Consequences

- `releases`・`active_release`・`release_history`・`release_jurisdictions`・`publish_control`・`publish_guard` を廃止する。新しい全体公開 ID・公開一覧・所属・guard の表を作らない。
- API は団体ごとの最も新しく登録した版、または指定した版を読み、取り込み済みの行をそのまま返す。
- 取り込み失敗時も反映済みの行を残し、同じ内容版の主キーで再実行する。件数と集計が取得中に変わることを許容する。
- 団体別の版と R2 の内容ハッシュ付き固定 URL を維持し、当面は過去版・配布物を自動削除しない。
- 共通の団体・COFOG マスタは版に依存させず、財政の表・dbt モデルには `fiscal_` を付ける。

初期案の全体公開一覧・一括切替・非公開候補は撤回した。最新の表・API・再実行条件は [設計書](../design-doc-jurisdiction-versions.md) を正本とする。現行 DB/API/CLI の置き換えは未実装である。
