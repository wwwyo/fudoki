# 全体の release と団体別の配布物の版を分ける

D1 の全体構築版とその公開参照に関する決定は、[ADR 0017](0017-jurisdiction-data-versions.md) の自治体データ版と公開一覧に置き換えた。以下は当時の決定を記録する。共通マスタ・Git manifest・R2 の団体別配布という方針は維持する。

全体の release に全団体のファイルをコピーすると、コードや別団体の更新だけでも未変更の配布物が増えるため、団体別の配布物に内容から決まる独立した版を付け、複数の release から同じ R2 キーを参照する。配布物の単位は現在の FDP と同じ団体全体とし、全ファイルの名前・SHA-256・サイズ・content type から `packageId` を決める。年度ごとに分ければ一年度の変更によるコピーを減らせるが、今回は団体別 FDP の一括取得と相対 resource path を保つ。

[ADR 0014](0014-git-distribution-manifest.md) により収録一覧は Git の `pipeline/publish/manifest.json` に統合し、配布物の実体を `fiscal/<団体コード>/<packageId>/` に置く。dataset は年度・歳入歳出・文書種別・原典版を区別するが、補正の号数と差額／補正後総額の意味は原典ハッシュでは分からず、補正予算の取得を追加する際に宣言する。D1 は候補と公開中を内部の構築 ID で区切り、共有 R2 配布物の削除は保持中の参照と処理中候補から使われていないものに限る。
