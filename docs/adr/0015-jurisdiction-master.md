# ADR 0015: 団体マスタを公開版から独立させる

状態: 採用（2026-10-01）

## 背景

団体コードで識別する団体のマスタが `release_id` を含む主キーを持っていた。団体の同一性と配布データの公開版を分ける必要がある。一方、最新のマスタだけを公開 API から読むと、候補の準備中や切り戻し後に既存の公開版の説明が変わる。

## 決定

`jurisdictions` は団体コードだけを主キーとし、Git の団体マスタから名称と OCD ID を生成する。publish はこの共通マスタを更新する。

`release_jurisdictions` は公開版・団体コードを主キーとし、団体マスタを外部キーで参照する。公開版の注意点と採用した名称・OCD ID の記録を保持する。`fiscal_datasets` はこの公開版の団体情報を参照し、公開 API もこの記録を読む。

共通マスタの JSONL は独立したハッシュで検査し、公開版別の8表の転送件数には含めない。空の旧 schema は初期化で置き換える。既存データがある旧 schema の自動変換は行わない。

## 結果と代替案

団体の同一性は公開版に依存しなくなる。マスタ更新が失敗した候補から残っても、公開中の API の説明は変わらず、切り戻し時も当時の説明を返せる。

名称・OCD ID の記録は公開版ごとに重複する。重複をなくして共通マスタへ直接 join する案は単純だが、公開版の説明を固定できないため採用しない。この記録は団体の改称・合併を有効日付きで管理する履歴マスタの代用ではない。
