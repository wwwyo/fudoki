# 配布物は団体ごと・正本と判断を別リソース

配布の単位は団体で、正本（expenditure/revenue）と判断（cofog 等）は別リソースに分ける。市が公表した事実と fudoki の判断を利用者が列で見分けられるようにするためで、`budget_line_id` で join できるので分けても失うものは無い。団体をまたぐ結合ファイルは作らない — 正本ごとに違うライセンスと出典を1つのライセンス表示に潰す害がある。団体をまたいで正本を揃えることもしない — 階層の構成が団体ごとに違い、揃えること自体が「同じ概念だ」という判断になる。

## Considered Options

- 判断を `derived/` へ団体をまたいで1ファイルに集める — 横断は派生ではなく glob で読めるので、配布物を畳む理由にならない
