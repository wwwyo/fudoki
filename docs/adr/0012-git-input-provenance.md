# 0012: 採用した入力の証跡を ingestion 配下で Git 管理する

- 日付: 2026-10-01
- 状態: Accepted（復元処理と36件の配置を反映、正規 lock の固定は遠隔保管の検証後）

採用した入力の `provenance.json` は36件で合計59,999 bytesであり、Git 肥大化の主因ではなく、抽出器の版・検査結果・利用条件を diff で確認する利点がある。原典と Parquet は R2、証跡は `pipeline/ingestion/fiscal/provenance/<論理入力パス>/provenance.json` に置き、`sources.lock.json` は R2 object key と Git の証跡ファイルへの相対パス・それぞれの SHA-256・サイズを記録する。作業ツリーには採用した入力の証跡だけを置き、過去の採用版は Git 履歴で辿る。全取得履歴の保存を追加する場合は R2 に分ける。

入力 lock の schema を2にし、復元時は証跡を Git から読み、内容ハッシュと原典・団体・年度の対応を検査してから R2 入力を復元する。証跡が欠ける・改変される場合は停止し、R2 の記録や最新の自治体資料で補わない。R2 転送・GET 照合が失敗した場合は正規 lock と採用証跡を更新しない。

ADR 0010 の証跡を R2 に置く決定を更新する。原典と表の遠隔保管はまだ未検証のため、移行用 lock と証跡は `.cache/migration/` にも用意し、正規 lock の固定を先行させない。Git に置いた既存の証跡の取得日時・抽出器名・検査内容は当時の記録を保持し、移行後の処理を実施したように書き換えない。
