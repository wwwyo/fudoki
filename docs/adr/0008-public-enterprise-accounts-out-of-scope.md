# 公営企業会計は配布対象から外す（専用の変換器を別の検討に）

公営企業会計（地方公営企業法の適用事業）は、収支科目が款項目節ではなく収益的収支・資本的収支＋勘定科目という別体系で経理される。予算自体は施行令17条2項で款・項に区分されるが、決算の構造は一般会計・特別会計の款項目節体系と共有できない。原典様式が違うので、現在の予算・決算変換器に混ぜて取り込むと「科目の無い特別会計」のように見えて静かに壊れる。

収録の実装は別の検討とする。東京の市町村はほぼ該当しない — 多摩26市町の水道は都水道局が運営（都営でないのは武蔵野・昭島・羽村・檜原の4団体のみ）、下水道は狛江市が2020年度に移行済み — ので、現状の収録に差し障りはない。

会計が特別会計から公営企業会計へ移ると同じ事業が原典から消える（狛江市の公共下水道、2018〜2019のみ収録）。`fund_directory` の sector はその時点の帳簿区分ではなく、調査の枠組みでの読みとして記録する —— 移行を「会計が減った」と誤読しないため。
