title: Quickstart
description: curl で風土記 API に最初のリクエストを投げる。
---

API キーは任意です。curl だけで、キー無しでも始められます（レート制限は匿名の方が低くなります）。キーを取りたい場合は [GitHub の Issue](https://github.com/wwwyo/fudoki/issues) で申請してください。手動発行後、`Authorization: Bearer <key>` ヘッダで送ります。制限を超えると `429` が返ります。

## 1. 収録されている団体を見る

```bash
curl 'https://api.fudoki.dev/v0/jurisdictions'
```

団体は総務省の全国地方公共団体コード（6桁）で識別されます。

## 2. 予算の一覧を見る

予算は「団体 × 年度」の単位で、id は `{団体コード}:{年度}` です。

```bash
curl 'https://api.fudoki.dev/v0/budgets'
```

filter で団体や年度を絞れます（文法は AIP-160 の部分集合。`=` と `AND` のみ）。

```bash
curl 'https://api.fudoki.dev/v0/budgets?filter=jurisdiction%20%3D%20%22132195%22'
```

## 3. 予算の明細を取る

`/budgets/{id}/budgetLines` が明細（行の集合）です。filter には `direction`（`expenditure` か `revenue`）が必須です。既定（`view=BASIC`）は軽量な形で、名称・金額（isPrimary の1段階）・共通の COFOG 項目だけを返します。

```bash
curl 'https://api.fudoki.dev/v0/budgets/132195:2023/budgetLines?filter=direction%20%3D%20%22expenditure%22&pageSize=10'
```

団体固有の科目階層（款・項・目など）や全段階の金額まで欲しいときは `view=FULL` を付けます（実在する budget を親にしたときだけ使えます）。

```bash
curl 'https://api.fudoki.dev/v0/budgets/132195:2023/budgetLines?filter=direction%20%3D%20%22expenditure%22&view=FULL&pageSize=10'
```

続きは応答の `nextPageToken` を `pageToken` に渡して辿ります。

## 4. 団体をまたいで COFOG で横断する

budget の id にワイルドカード `-` を指定すると、全予算を COFOG（政府機能分類）で横断できます。filter には `cofog.division` が必須です。横断の親（`-`）では団体固有の階層に意味が無いため `view=FULL` は使えません（400 になります）。

```bash
curl 'https://api.fudoki.dev/v0/budgets/-/budgetLines?filter=cofog.division%20%3D%20%2209%22&pageSize=10'
```

division `09` は教育です。横断応答の各行は親 budget への参照を持ち、そこから `view=FULL` で団体固有の形の行へ戻れます。

## 5. 配布物そのものを取る

API を経由せず、正本の配布物（Fiscal Data Package）をバイト同一で取得できます。

```bash
curl 'https://api.fudoki.dev/v0/datapackages/132195/datapackage.json'
```

応答ヘッダの `X-Fudoki-Revision` が由来する配布物の revision（git commit）、`ETag` がファイルの SHA-256 です。
