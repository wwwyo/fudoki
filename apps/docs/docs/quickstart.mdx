API キーは任意です。キー無しでも始められ、キーは `Authorization: Bearer <key>` で送ります。制限を超えると `429` が返ります。

## 団体と文書を選ぶ

```bash
curl 'https://api.fudoki.dev/v0/jurisdictions'
curl 'https://api.fudoki.dev/v0/fiscal-datasets?jurisdictionCode=132195&direction=expenditure'
```

応答の `releaseId` と dataset の `id` を使います。dataset は団体・年度・歳入歳出・文書種別・原典版を識別します。同じ年度に予算書と決算書がある場合も別 dataset です。`phases` はその文書で利用できる金額段階を示します。

## 明細と集計を取得する

以下の値は、実際の一覧応答の ID と利用可能な段階に置き換えます。

```bash
curl 'https://api.fudoki.dev/v0/fiscal-lines/query' \
  -H 'Content-Type: application/json' \
  -d '{"releaseId":"<releaseId>","datasetIds":["<datasetId>"],"phase":"executed","pageSize":50}'

curl 'https://api.fudoki.dev/v0/fiscal-datasets/aggregate' \
  -H 'Content-Type: application/json' \
  -d '{"releaseId":"<releaseId>","datasetIds":["<datasetId>"],"phase":"executed","groupBy":["cofog.division"],"consolidation":"retained"}'
```

金額は円の整数で返します。原典の金額と単位、名称の出所、分類の判断根拠も明細に含めます。次ページは `nextCursor` を同じ問い合わせの `cursor` に渡します。公開版が切り替わっても保持中の版を使い、期限切れは `410`、問い合わせの変更は拒否します。

団体間の比較では `groupBy` に `jurisdiction`、年度間では `year` を含めます。同じ団体・年度・歳入歳出の複数文書をまとめた集計は二重計上の恐れがあるため拒否します。収録していない金額段階へ自動で置き換えません。

名称検索は `/v0/fiscal-lines/search` に `name` を指定します。完全な文字列の部分一致で検索し、SQL やワイルドカードの式として解釈しません。

## 一括配布を取得する

```bash
curl 'https://api.fudoki.dev/v0/files?jurisdictionCode=132195'
```

応答の `manifestUrl` と各 `url` が独立した download Worker を指します。release を含む URL は不変で、API/D1 を利用できなくても配布ファイルを取得できます。`ETag` は取得したファイルの SHA-256、`X-Fudoki-Release` は release ID です。API はファイル本体を転送しません。

API が使えない場合は download の公開版一覧から辿れます。

```bash
curl 'https://download.fudoki.dev/releases'
curl 'https://download.fudoki.dev/releases?cursor=<nextCursor>'
```

一覧の `manifestUrl` は download origin に対する相対 URL です。完成した公開用 manifest がある版だけを返します。`nextCursor` があれば一覧が空でも続きを取得してください。

入出力の完全なスキーマは [API リファレンス](/reference) にあります。
