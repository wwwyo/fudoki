風土記（fudoki）は、日本の地方自治体の支出を事業単位（目）まで構造化し、外部データと join 可能な形で配布するプロジェクトです。**正本はリポジトリ**（[github.com/wwwyo/fudoki](https://github.com/wwwyo/fudoki)）にあり、この API はそこから生成した派生物です。

## 何ができるか

- 団体（jurisdictions）と予算（budgets、団体 × 年度）のメタデータを引ける
- 予算の明細（statement）を、団体固有の科目階層と金額つきで取得できる。歳出と歳入の両方を扱う
- COFOG（国際的な政府機能分類）で団体をまたいだ横断検索ができる
- 配布物（Fiscal Data Package）そのものをバイト同一で取得できる（datapackages）

## Base URL

```
https://api.fudoki.dev/v0
```

REST（OpenAPI 準拠）の読み取り専用 API です。API キーは任意です ── 無くても叩けますが、キーを送るとレート制限が緩和されます。キーは手動発行で、[GitHub の Issue](https://github.com/wwwyo/fudoki/issues) で申請してください。制限を超えると `429` が返ります。応答はすべて、由来する配布物の revision（git commit）を持ちます。

**実験版（v0）**のため URL と応答スキーマには破壊的変更があり得ますが、データの識別子（`budget_line_id`、全国地方公共団体コード）は配布物側の契約であり、API の版とは独立です。ただし安定するのは同一原典・同一の導出規則の範囲で、自治体が原典の科目名称を改めると `budget_line_id` は変わることがあります（詳細は各団体の caveats）。
