風土記は、日本の地方自治体の支出を事業単位（目）まで構造化し、外部データと join 可能な形で配布するプロジェクトです。宣言・分類判断・採用した入力一覧は [GitHub](https://github.com/wwwyo/fudoki)、原典と取り込み済みの表は非公開 R2、証跡は Git に保存します。API の D1 はこれらから再生成する検索用の表です。

## 何ができるか

- 団体と dataset のメタデータを取得する。dataset は団体・年度・歳入歳出・文書種別・原典版を区別する
- 文書を指定して、金額一つの明細を取得する。科目階層・名称・COFOG 分類でも絞り込める
- dataset を明示して、団体・年度・COFOG ごとに集計する
- 配布物（Fiscal Data Package）を取得する。API が返す配布 URL から、公開 R2 のカスタムドメインがファイルを提供する
- 当初予算・補正や繰越などの変更・決算との対応を取得する。入力が足りない範囲の予算額は未確認として扱う
- 同じ問い合わせを [MCP server](/mcp) から利用する

## Base URL

```
https://api.fudoki.dev/v0
```

REST（OpenAPI 準拠）の読み取り専用 API です。API キーは任意で、キーを送るとレート制限が緩和されます。キーは手動発行で、[GitHub の Issue](https://github.com/wwwyo/fudoki/issues) で申請してください。制限を超えると `429` が返ります。

応答の `versions` は団体コードと内容の版を示します。比較や次ページの取得は団体別の版に固定できます。版を指定しない場合は最新の登録版を使い、取り込み途中の明細も応答に含みます。決算は実績、当初予算は当初額をそれぞれ `amount` 一つで返します。集計は同じ団体・年度・歳入歳出につき一つの文書・原典版を選びます。

**実験版（v0）**のため URL と応答スキーマには破壊的変更があり得ます。`fiscal_line_id` は dataset と原典の行を含み、異なる原典版の明細を同じ ID として扱いません。
