風土記は、日本の地方自治体の支出を事業単位（目）まで構造化し、外部データと join 可能な形で配布するプロジェクトです。宣言・分類判断・採用した入力一覧は [GitHub](https://github.com/wwwyo/fudoki)、原典と取り込み済みの表・証跡は非公開 R2 に保存します。API の D1 はこれらから再生成する検索用の表です。

## 何ができるか

- 団体と dataset のメタデータを取得する。dataset は団体・年度・歳入歳出・文書種別・原典版を区別する
- 原典の行と金額段階を指定して明細を取得する。科目階層・名称・COFOG 分類でも絞り込める
- dataset と金額段階を明示して、団体・年度・COFOG ごとに集計する
- 配布物（Fiscal Data Package）を取得する。API が返す配布 URL から、独立した download Worker が R2 のファイルを提供する
- 同じ問い合わせを [MCP server](/mcp) から利用する

## Base URL

```
https://api.fudoki.dev/v0
```

REST（OpenAPI 準拠）の読み取り専用 API です。API キーは任意で、キーを送るとレート制限が緩和されます。キーは手動発行で、[GitHub の Issue](https://github.com/wwwyo/fudoki/issues) で申請してください。制限を超えると `429` が返ります。

応答の `releaseId` は配布物と検索用の表の公開版を表します。比較や次ページの取得は同じ release に固定できます。予算書と決算書の金額を重ねて足さないよう、集計は同じ団体・年度・歳入歳出につき一つの文書・原典版を選びます。

**実験版（v0）**のため URL と応答スキーマには破壊的変更があり得ます。`fiscal_line_id` は dataset と原典の行を含み、異なる原典版の明細を同じ ID として扱いません。
