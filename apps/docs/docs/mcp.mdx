REST API と同じ予算・決算データを、MCP server としても提供しています。問い合わせの文法やエンドポイントを知らなくても、MCP client に URL を登録するだけで、自然言語の問いから予算を引けます。tool はすべて読み取り専用で、認証は不要です。

## Endpoint

```
https://api.fudoki.dev/mcp
```

MCP の Streamable HTTP transport に沿った remote サーバです。認証は不要ですが、API キーを `Authorization: Bearer <key>` ヘッダで送ると REST API と同じレート制限の緩和を受けられます。

## client に登録する

Claude Code の場合はコマンド1行です。

```bash
claude mcp add --transport http fudoki https://api.fudoki.dev/mcp
```

設定ファイルで登録する client では、URL で HTTP transport を指す形になります（キー名は client によって違い、`"type": "http"` の併記が要るものもあります）。

```json
{
  "mcpServers": {
    "fudoki": {
      "url": "https://api.fudoki.dev/mcp"
    }
  }
}
```

API キーを付けるときは、Claude Code では `--header "Authorization: Bearer <key>"`、JSON 設定の client では `headers` フィールドで指定します（キーの発行は [Quickstart](/quickstart) を参照）。

stdio しか話せない client からは `mcp-remote` などのブリッジを介して接続してください。

⚠️ **ブラウザ上で動く client は制限があります。** `/mcp` は Origin ヘッダを allowlist（`https://fudoki.dev` と `http://localhost:5173`）で検証しており、それ以外のサイトにホストされた client からの接続は 403 で拒否されます。第三者のサイトが利用者のブラウザ経由で匿名のレート制限枠を消費するのを防ぐためです。Origin を送らないデスクトップの client は制限されません。

## Tools

| tool | 返すもの |
|---|---|
| `list_jurisdictions` | 団体と、収録範囲・出典に関する注意点 |
| `list_fiscal_datasets` | 団体・年度・歳入歳出・文書種別・原典版で区別した文書一覧 |
| `get_fiscal_dataset` | 選択した文書の出典・文書種別・階層・会計 |
| `get_fiscal_lines` | 選択した dataset の金額一つの明細、名称の出所と歳出の分類根拠 |
| `search_fiscal_lines` | 原典の名称と判断による名称の文字列部分一致検索 |
| `aggregate_fiscal_datasets` | 選択した文書での集計。団体間・年度間の比較は各団体・年度を分ける |
| `get_fiscal_budget_history` | 当初予算、符号付き変更額、決算との対応と収録状況 |
| `list_files` | 団体別の版に対応する配布ファイルの R2 URL |

## 応答の約束

各応答の `versions` は団体別の内容の版を示します。文書を選んで明細と集計を取得し、同じ団体・年度・歳入歳出の複数文書の合算は拒否します。金額は円の整数です。予算変更は変更額を返し、必要な原典が未収録の場合は予算額を未確認として扱います。

明細の `nextCursor` は問い合わせと団体別の版に固定され、有効期限は1時間です。集計の `datasets` は対象文書・出典を示します。tool の入出力は REST API と同じ契約を使います。[Quickstart](/quickstart) と [API リファレンス](/reference) を参照してください。
