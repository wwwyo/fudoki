REST API と同じ予算データを、MCP server としても提供しています。filter 文法やエンドポイントを知らなくても、MCP client に URL を登録するだけで、自然言語の問いから予算を引けます。tool はすべて読み取り専用で、認証は不要です。

## Endpoint

```
https://api.fudoki.dev/mcp
```

transport は Streamable HTTP で、応答は SSE ではなく単発の JSON が返ります。プロトコル版は 2025-11-25 系と 2026-07-28 の両方を受理するので、client 側で版を意識する必要はありません。

サーバは stateless で、セッションを持ちません。「前の呼び出しで収録範囲を確認した」という状態をサーバが次の呼び出しで覚えていることはありません。その代わり、数値を返す応答には計算に使った条件（団体・年度・歳出歳入・予算段階・会計範囲）が必ず同梱されます。

レート制限は REST API と共通で、匿名の方が厳しめです。API キーを持っている場合は `Authorization: Bearer <key>` ヘッダで送れます。ヘッダを設定できる client であれば、MCP 経由でも同じ緩和を受けられます。

## client に登録する

Claude Code の場合はコマンド1行です。

```bash
claude mcp add --transport http fudoki https://api.fudoki.dev/mcp
```

設定ファイルで登録する client では、URL で HTTP transport を指す形になります（キー名は client によって違い、`"type": "http"` の併記が要るものもあります）。

```json
{
  "mcpServers": {
    "fudoki": {
      "url": "https://api.fudoki.dev/mcp"
    }
  }
}
```

stdio しか話せない client からは `mcp-remote` などのブリッジを介して接続してください。

⚠️ **ブラウザ上で動く client は制限があります。** `/mcp` は Origin ヘッダを allowlist（`https://fudoki.dev` と `http://localhost:5173`）で検証しており、それ以外のサイトにホストされた client からの接続は 403 で拒否されます。第三者のサイトが利用者のブラウザ経由で匿名のレート制限枠を消費するのを防ぐためです。Origin を送らないデスクトップの client は制限されません。

## Tools

| tool | 返すもの |
|---|---|
| `list_jurisdictions` | 収録団体の一覧。各団体の caveats に、予算段階や会計範囲など数値の意味を変える注意事項が入る |
| `list_budgets` | 収録予算（団体 × 年度）の全件。各 budget の scopes に、その団体・年度で実在する予算段階（phase）・会計（fund）・COFOG 到達度が入る |
| `get_budget_lines` | 予算の明細。`budget` に `{団体コード}:{年度}` を指定するほか、`-` で全予算を COFOG で横断できる。`view=FULL` で団体固有の科目階層と全段階の金額まで取れる |
| `aggregate_budgets` | COFOG 別・科目階層（款・項）別・年度別の集計。`direction` と `phase` は必須 |
| `search_budget_lines` | 名称の部分一致で明細を横断検索。原典の科目名と、fudoki が対応づけた事業名の両方を対象にする |

## 応答の約束

このサーバは「答えられない問いに数値を返さない」ことを中心に据えています。

- 条件が定まらない集計（歳出歳入の別や予算段階が定まらないもの）や、収録範囲の外にある問いには、数値を含まない応答が返ります。エラー応答には `reason`（理由）と `allowedValues` / `supportedGroupings`（次に指定できる値）が入っており、client の言語モデルが問いを組み立て直せるようになっています
- 数値を返す応答には、その数値を計算した条件（団体・年度・歳出歳入・予算段階・会計範囲）が同梱されます
- すべての応答は由来する配布物の `revision`（git commit）を持ちます。集計と検索の応答には `provenance`（使った原典と、そのまま表示できる帰属文）も含まれます

tool の入出力は REST API と同じ contract に基づきます。各フィールドの意味は [API リファレンス](/reference) を参照してください。
