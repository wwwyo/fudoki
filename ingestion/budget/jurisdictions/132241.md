# 多摩市（132241）

当初予算の一般会計（歳出・歳入）を令和3〜6年度の4年度分収録している。
原典は CC BY 4.0（東京都オープンデータカタログのライセンス表示）。

⚠️ **令和5・6年度はカタログに登録が無く、市サイトの URL を宣言して取っている。**
カタログのリソース登録は令和4年度で止まっているが、原典は市の「予算・決算についての資料」ページに
同じ書式で置かれている。証跡の `resource_url_declared` がどちらの経路で取ったかを持つ。

実測は `bun run survey:structure 132241`（観測は commit しない）。以下は 2026-08-30 の実測にもとづく。

## 三鷹市とも狛江市とも書式が違う

**コードと名称が別々の列にある。** `款` と `款名称`、`細目` と `細目名称` のように階層ごとに対で持つ。
三鷹市（1セルに「2桁コード + 名称」）とも狛江市（コードだけで階層ごとの名称が無い）とも違う。
宣言は `budget_code_style: code-only` + `budget_label_columns` の全階層宣言で表している
（セルがコードだけである点は狛江市と同じで、違うのは名称の列が全階層にあることだけなので、style は増やしていない）。

**事業階層の呼び名は「細目」で、名称を持つ。** 例: `子ども若者育成支援事業`。
狛江市の「大事業」が名称を持たないのと対照的で、収録した時点で事業名が揃う。

⚠️ **歳出と歳入で階層の並びが違う。**

| | 階層 |
|---|---|
| 歳出 | 款 → 項 → 目 → **細目** → 節 |
| 歳入 | 款 → 項 → 目 → 節 → **細節** |

歳入には細目に相当する階層が無い。原典の列の並びがそのまま違うので、宣言も direction ごとに分けてある。

## 会計にコードが無い

列は `会計名称` だけで、値は `一般会計` の1種類。原典がコードを持たないので、
`budget_levels_without_code` に宣言して `fund_code` を空にし、名称だけを持たせている。
**無いものを埋めないため**の宣言で、この宣言が無いと staging が名称を code に入れ、
「コードは数字」という検査に名称が引っかかる。

## コードのゼロ埋めが年度で変わる

| 年度 | 款・項・目・節 | 細目 |
|---|---|---|
| 令和3年度 | `01` 固定2桁 | `001` 固定3桁 |
| 令和4〜6年度 | `1`（ゼロ埋めなし） | `100` |

**同じ団体の同じ資料で表記が割れる**ので、コードで年度をまたいで突き合わせることはできない。
科目マスタへの対応表（`account_map.csv`）は両表記を登録してある。

## 階層だけで行が一意

2022年度（令和4年度）の歳出 1,440 行が 1,440 通り、歳入 473 行が 473 通り。
狛江市のような所属・予算区分の列は無いので `budget_extra_key_columns` は空。

## 金額は1段階だけ。単位は千円だが原典が名乗っていない

金額列は `予算額` の1つで、当初予算（phase = approved）。決算書の狛江市と違い、
package 段で段階ごとの行へ展開する必要が無い。

⚠️ **列名が単位を名乗っていない**ので、狛江市の `予算現額(千円)` のような原典との突き合わせが効かない。
千円だと判断した根拠は次の2つ。

- 歳出と歳入の合計が年度ごとに完全に一致する（R3 = 63,030,000 / R4 = 63,067,000 /
  R5 = 58,730,000 / R6 = 61,790,000。いずれも差 0）
- それを千円と読むと 587〜630 億円で多摩市の一般会計当初予算の規模に合う（円と読むと 0.63 億円で成り立たない）

⚠️ **令和7年度は円になっている**（下記）。単位が年度で変わる団体なので、**次の年度を足すときに前年度の宣言を写さないこと**。

## 歳入の款コードが法定から2つずれる

多摩市の歳入は款8がゴルフ場利用税交付金、款10が国有提供施設等所在市町村助成交付金で、
以降が法定より2つ繰り下がっている（多摩市の11地方特例交付金 = 法定の9地方特例交付金）。

**これは誤りではない。** 地方自治法施行規則 別記の歳入の備考2が、

> 特別とん譲与税法第1条の開港所在市町村、航空機燃料譲与税法第1条の空港関係市町村、
> 地方自治法第252条の19第1項の指定都市、道路法第7条第3項に規定する指定市、
> 地方税法第103条に規定するゴルフ場所在市町村又は国有提供施設等所在市町村助成交付金に
> 関する法律第1項の規定の適用を受けることとなる市町村にあつては、市町村の欄の款の欄中
> 「9地方特例交付金」を「13地方特例交付金」とし、以下順次4号ずつ繰り下げ、

として条件付きの読み替えを定めている。多摩市はこのうち2つ（ゴルフ場所在市町村・国有提供施設等）に
該当するため、2款ぶん繰り下がっている。

⚠️ **この2つの款は基本の表（`account_master.csv`）に無い**ので `master_kind` は `addition` で、
対応先の `master_kan_code` は空である。**マスタの抽出漏れではない** —
`fetch:account-master` は基本の表だけを起こしており、備考の読み替え規定は起こしていない。
一度これを抽出漏れだと誤読したので、同じ疑いを持ったときは PDF の 9〜12 ページを見ること
（そこにあるのは表の続きではなく、備考とその読み替え後の表の引用である）。

## 科目マスタへの対応で表記差が出たもの

| 多摩市 | マスタ | |
|---|---|---|
| 農林業費 | 農林水産業費 | 水産業の項が無く名称を短くしている |
| 道路橋りょう費 | 道路橋りよう費 | 拗音を大書きする様式の記法 |
| 延滞金・加算金及び過料 | 延滞金、加算金及び過料 | 並列の区切りが中黒か読点か |
| 公共土木施設／公園施設／文教施設／その他公共、公用施設 災害復旧費 | 何施設災害復旧費 | 様式の「何」に施設の種類を入れた形 |
| 新型コロナウイルス感染症対策地方税減収補**てん**特別交付金 | （法定に無い。addition） | ⚠️ 三鷹市は「補**填**」で原典の表記が違う |

法定の項に無く `addition` として登録したもの: 国民年金費（民生費）、小切手支払未済償還金（諸支出金）。
どちらも様式の備考1が認める行政権能の差による追加にあたる。

## COFOG

規則18本で全 6,024 行（4年度）に規則が当たり、分類不能は年度あたり2行だけ。

- 予備費: 執行されるまで機能が決まらない
- その他公共、公用施設災害復旧費: 対象施設が特定できない

災害復旧費は COFOG が機能別なので、復旧の対象施設の機能に置いた（文教 → 09・道路 → 04・公園 → 08）。
社会教育費のうち図書館費を 08 に置くのは三鷹市・狛江市と同じ扱い。
保健体育費は学校給食費だけ 09（教育に付帯するサービス）で、それ以外は 08 に置いた。

## 収録できていないもの

⚠️ **令和7年度は書式が変わっており、いまの宣言では足せない。**

| | 令和3〜6年度 | 令和7年度 |
|---|---|---|
| 金額の列名 | `予算額` | `合計 / 予算額` |
| 単位 | 千円 | **円**（歳出計 68,550,000,000 = 685.5 億円） |
| 年度の列 | 歳出・歳入とも あり | **歳出だけ無い**（歳入には残っている） |

`budget_amounts` も `budget_source_year_columns` も (団体, 方向) の粒度なので、
**年度で単位や列名が割れる団体を表せない**。足すには宣言を年度の粒度へ広げる必要があり、
それは既存2団体にも効く構造変更になる。

令和2年度以前はカタログに登録が残っているが実体が 404 で、市サイトの一覧にも無い。
**多摩市は5年度ぶんしか残さない運用に見える**ので、消える前に取ることに意味がある。

**特別会計は原典が別ファイル**で、`raw/` の partition が (団体, 年度, 段階, 方向) なので
同じ方向に2本を置けない。一般会計だけを収録している（科目マスタの適用範囲も一般会計）。

**「決算事業報告書データ」（事業カルテ・事業別歳出決算額一覧表）が令和元〜3年度ぶんカタログにある**が、
**実体は CSV・XLS・PDF（236件）のすべてが 404 で、ランディングページ自体も 404**（2026-08-30 実測）。
カタログにメタデータだけが残り、市サイトからは公開ごと消えている。
多摩市に執行額を足せる唯一の経路だったので、市へ照会する価値がある
（狛江市と違い、名称を補うための PDF は要らない。多摩市の CSV は全階層に名称を持つ）。
