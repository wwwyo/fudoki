# 三鷹市（132047）

令和6年度 当初予算。東京都カタログ CKAN の「【予算・決算】予算情報」から収録
（会計 / 款 / 項 / 目 / 事項 / 節 / 細々節 / 予算額。5,613行、平成28〜令和6の9年分が同形式）。

会議録は `gate.fetch: deny / redistribute: review` だが、予算はカタログのライセンスが CC BY なので配布できる
（③のゲートを①に繋ぐと止まる、の実例）。

## 原典の癖（実測）

- **機種依存文字がある。** `01Ⅰ型事業委託料` の Ⅰ（U+2160、CP932 で 0x8754）。
  素の `shift_jis` では復号できない。`cp932` を使い、復号が可逆であることを検査する
- **全角スペースが混じる。** `01郵便料　`。全 45,038 セル中3セル。
  TS 版が `.trim()` で黙って落としており、1団体目を配るまで誰も知らなかった。
  いまも trim するが（識別子は公開 API なので変えられない）、警告として毎回出す
- **和暦の表記が元号で揺れている。** 令和は全角（`令和６年度`）、平成は半角（`平成30年度`）。
  年度の唯一の出所がリソース名なので、ここを間違えると年度を取り違える
- **歳出と歳入で階層の構成が違う。** どちらも7階層だが、歳出は目と節の間に「事項」、
  歳入は節と細々節の間に「細節」。Design Doc は歳入を6階層としていたが、原典は細々節を持つ7階層だった
- **細々節のコードは同じ節の下で再利用される**（実測 710 箇所・1,615 行）。
  コードのパスでは識別子を作れないので、パスの構成要素をセル全文（コード + 名称）に取ってある。
  副作用として、自治体が名称を直すと識別子が変わる
- **年度で会計の範囲が変わる。** 令和2年度以降は5会計、平成28〜令和元年度は下水道事業特別会計を含む6会計
- **令和4年度の歳入だけ引用符付きのセルがある**（786行）。収録には引用符を解釈するパーサが要る
  （`bun run survey:budget-years`）
- **歳出と歳入の合計一致は9年度すべてで成立した。** ただし当初予算に限った条件付き検算のままにしてある

## COFOG

- **款だけでは決まらない款が実在した。** 衛生費・土木費・教育費は項へ、
  公債費と都市計画費と生涯学習費は目へ下げて決着した
- 目の名称に受け皿の会計名が入っているので、会計間の繰出金と繰入金を対にして消去できた

## 科目マスタとの対応

- 款コードは `01`〜`12`（ゼロ埋め）。**法定とずれる** — 災害復旧費（法定11）と諸支出金（法定13）を
  持たないため、11 公債費→法定12、12 予備費→法定14
- 款6 の原典名は「農林費」（法定は「農林水産業費」）。水産業費・林業費の項を持たない市の略称と読む
- 項「道路橋梁費」はマスタの「道路橋りよう費」と表記差（`account_map.csv` に明示）
- 「スポーツ推進費」「生涯学習費」は法定の項に無い。マスタの保健体育費・社会教育費に相当する領域の
  再編と読めるが、同一と決める根拠が無いので `kind=addition`
