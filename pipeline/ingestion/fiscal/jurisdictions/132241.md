# 多摩市（132241）

当初予算の一般会計と国民健康保険・介護保険・後期高齢者医療の3特別会計（歳出・歳入）を
令和3〜7年度の5年度分、固定入力へ採用している（2026-10-04）。採用済みの正本は
`sources.lock.json` と個別の証跡であり、全年度・補正・決算の完了を表さない。
令和8年度の当初予算はPDFが公開されているが、このCSV経路には未採用である。
決算事業報告2022〜2024年度のCSVには事業別決算額と財源内訳があり、節はない。
独立した原典粒度として取り込む作業は残る。公開・探索・未採用範囲は `sources.json` に記録する。

## 2021〜2025年度の既存CSVの公開・取得根拠

⚠️ **既存CSVは2021〜2025年度とも CC BY 4.0 だが、その表示の出どころが年度で違う。**
令和3・4年度は東京都オープンデータカタログのライセンス表示、
令和5〜7年度はカタログに登録が無いので市サイト「予算・決算についての資料」の
当該年度の節に置かれた表示が根拠である（2026-08-30 実測）。
**カタログに登録の無いものへカタログのライセンスは援用できない。**
配布物の出典表示も年度ごとに1行ずつ並ぶ（先頭の1件で代表させると3年度ぶん誤った帰属になる）。
年度ごとの根拠は `pipeline/ingestion/fiscal/sources.json` の `redistribute_basis` が持つ。

⚠️ **令和5〜7年度はカタログに登録が無く、市サイトの URL を宣言して取っている。**
カタログのリソース登録は令和4年度で止まっているが、原典は市の「予算・決算についての資料」ページに
置かれている。証跡の `resource_url_declared` がどちらの経路で取ったかを持つ。

⚠️ **この年度の再配布の根拠はカタログではなく市サイトにある。** ページは年度ごとに節が切られ、
各節に CC BY 4.0 の表示が直接置かれている（2026-08-30 実測）。カタログに登録が無いものへ
カタログのライセンスを援用することはできないので、`redistribute_basis` はそちらを指している。

⚠️ **年度の裏づけも同じページにある。そして機械は見ていない。** ページには PDF が1本も無く
（CSV だけ）、年度を言っているのは見出し「令和7年度予算についての資料」と
リンクテキスト「令和7年度一般会計歳出（当初予算）」である。他の年度で CKAN の
`resource_name` が果たしている役割をこれが果たしているが、**直 URL では取得時の
リソース名照合が自己参照になる**ので、`fetch.py` は年度を一度も照合していない。
根拠は `url_basis` に文章として残してある。
歳入には原典に `年度`（`R7`）の列があるので、そちらだけは partition と照合されている。

実測は `bun run survey:structure 132241`（観測は commit しない）。以下は 2026-08-30 の実測にもとづく。

## 三鷹市とも狛江市とも書式が違う

**コードと名称が別々の列にある。** `款` と `款名称`、`細目` と `細目名称` のように階層ごとに対で持つ。
三鷹市（1セルに「2桁コード + 名称」）とも狛江市（コードだけで階層ごとの名称が無い）とも違う。
宣言は `budget_code_style: code-only` + `budget_label_columns` の全階層宣言で表している
（セルがコードだけである点は狛江市と同じで、違うのは名称の列が全階層にあることだけなので、style は増やしていない）。

**事業階層の呼び名は「細目」で、名称を持つ。** 例: `子ども若者育成支援事業`。
狛江市の「大事業」が名称を持たないのと対照的で、収録した時点で事業名が揃う。

⚠️ **歳出と歳入で階層の並びが違う。**

| | 階層 |
|---|---|
| 歳出 | 款 → 項 → 目 → **細目** → 節 |
| 歳入 | 款 → 項 → 目 → 節 → **細節** |

歳入には細目に相当する階層が無い。原典の列の並びがそのまま違うので、宣言も direction ごとに分けてある。

## 会計にコードが無い

会計を表す列は `会計名称` だけで、一般会計と3特別会計の名称を持つ。原典が会計コードを持たないので、
`budget_levels_without_code` に宣言して `fund_code` を空にし、名称だけを持たせている。
**無いものを埋めないため**の宣言で、この宣言が無いと staging が名称を code に入れ、
「コードは数字」という検査に名称が引っかかる。

| 年度 | 款・項・目・節 | 細目 |
|---|---|---|
| 令和3年度 | `01` 固定2桁 | `001` 固定3桁 |
| 令和4〜7年度 | `1`（ゼロ埋めなし） | `100` |

2025年度（令和7年度）も歳出 1,610 行が 1,610 通り、歳入 552 行が 552 通り。

## 金額は1段階だけ。ただし列名も単位も年度で割れる

金額は1列で当初予算（phase = approved）の1段階だけ。決算書の狛江市と違い、
marts で段階ごとの行へ展開する必要が無い。

| 年度 | 列名 | 単位 |
|---|---|---|
| 令和3〜6年度 | `予算額` | 千円 |
| **令和7年度** | **`合計 / 予算額`** | **円** |

⚠️ **列名が単位を名乗っていない**ので、狛江市の `予算現額(千円)` のような原典との突き合わせが効かない。
単位を読み取った根拠は次の2つ。

- 歳出と歳入の合計が年度ごとに完全に一致する（R3 = 63,030,000 / R4 = 63,067,000 /
  R5 = 58,730,000 / R6 = 61,790,000 / R7 = 68,550,000,000。いずれも差 0。2026-08-30 実測）
- その額が多摩市の一般会計当初予算の規模として読める。R3〜R6 を千円と読むと 587〜630 億円、
  R7 を円と読むと 685.5 億円で連続する（R3〜R6 を円と読むと 0.63 億円、
  R7 を千円と読むと 68.5 兆円で、どちらも成り立たない）

宣言は `budget_amounts` の各項目が `years` を持つ形で表してある。
**単位が年度で割れるので、descriptor の定数にはできない** — 配布物は行の列
（`source_amount_unit`）で単位を持ち、円へ直した値は `value` にある。
⚠️ **年度をまたいで足すときは `source_amount` ではなく `value` を使うこと。**

⚠️ **次の年度を足すときに前年度の宣言を写さないこと。** この団体は書式が年度で変わる。

## 歳入の款コードが法定から2つずれる

多摩市の歳入は款8がゴルフ場利用税交付金、款10が国有提供施設等所在市町村助成交付金で、
以降が法定より2つ繰り下がっている（多摩市の11地方特例交付金 = 法定の9地方特例交付金）。

**これは誤りではない。** 地方自治法施行規則 別記の歳入の備考2が、

> 特別とん譲与税法第1条の開港所在市町村、航空機燃料譲与税法第1条の空港関係市町村、
> 地方自治法第252条の19第1項の指定都市、道路法第7条第3項に規定する指定市、
> 地方税法第103条に規定するゴルフ場所在市町村又は国有提供施設等所在市町村助成交付金に
> 関する法律第1項の規定の適用を受けることとなる市町村にあつては、市町村の欄の款の欄中
> 「9地方特例交付金」を「13地方特例交付金」とし、以下順次4号ずつ繰り下げ、

として条件付きの読み替えを定めている。多摩市はこのうち2つ（ゴルフ場所在市町村・国有提供施設等）に
該当するため、2款ぶん繰り下がっている。

⚠️ **この2つの款は基本の表（`account_master.csv`）に無い**ので `master_kind` は `addition` で、
対応先の `master_kan_code` は空である。**マスタの抽出漏れではない** —
`fetch:account-master` は基本の表だけを起こしており、備考の読み替え規定は起こしていない。
一度これを抽出漏れだと誤読したので、同じ疑いを持ったときは PDF の 9〜12 ページを見ること
（そこにあるのは表の続きではなく、備考とその読み替え後の表の引用である）。

## COFOG

規則18本で全 7,634 行（5年度）に規則が当たり、分類不能は年度あたり2行だけ。

- 予備費: 執行されるまで機能が決まらない
- その他公共、公用施設災害復旧費: 対象施設が特定できない

災害復旧費は COFOG が機能別なので、復旧の対象施設の機能に置いた（文教 → 09・道路 → 04・公園 → 08）。
社会教育費のうち図書館費を 08.2 に置くのは三鷹市・狛江市と同じ扱い。
保健体育費は学校給食費だけ 09.6（教育に付帯するサービス）で、それ以外は 08.1 に置いた。

**割当の粒度は group まで降りたものが 46%、class まで降りたものが 3%**（令和3〜6年度で実測）。
残りは division 止まりで、款の名称だけで決まる規則（総務費 → 01、民生費 → 10）がそれにあたる。
group を埋めるには項や目まで下げる判断が要るので、**空は「該当が無い」ではなく「まだ降りていない」**。

学校教育は3本に分かれている。教育総務費が 09.8（他に分類されない教育。教育委員会・事務局・
教育指導の管理業務で特定の学校段階に属さない）、小学校費と幼稚園費が 09.1（就学前教育及び初等教育）、
中学校費が 09.2（中等教育）。⚠️ **division では1本で済んでいたものが、group では割れる。**

## 年度の列は歳出だけ令和7年度で消えた

歳入には全年度 `年度`（`R7` の形）があるが、**歳出は令和7年度から列そのものが無い**。
`budget_source_year_columns` の歳出側は `years: [2021, 2022, 2023, 2024]` で絞ってあり、
外した年度で本当に列が無いことは `tests/source_year_column_scope_is_real.sql` が確かめる
（絞れば照合を素通りできてしまうので、逃げ道を塞いでいる）。

⚠️ **年度で列構成が違うので、raw の Parquet は `union_by_name=true` で読んでいる**
（`_sources.yml`）。無い列は NULL として読まれるので、**この団体でだけ
列名の書き間違いが黙って NULL になる経路が開く**。塞いでいるのは
`amount_declarations_cover_years`（宣言が原典の全年度を覆っているか）と、
従来からの `canonical_preserves_source`（原典と staging の多重集合一致）である。
