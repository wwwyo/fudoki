## なぜこの団体が1団体目か

東京62団体の取得元を確定させた調査（`pipeline/ingestion/fiscal/observations/`）で、
**59団体は事業単位の資料を PDF でしか出していない**。昭島市はその中で

- 再配布 stance が `allow`。しかも**PDL1.0 を標準ライセンス名で明示**している唯一の団体
  （もう1つの `allow` である千代田区は利用規約の文章）
- 予算書が会計別に分冊されず、一般会計が1本の PDF（`splitInto: 1`）
- テキストが素直に取れる（`charsPerPage` 413。アウトライン化も文字化けも無い）
- 令和2〜8年度が同じ導線に揃っている

という条件が揃っていた。経路を通すのに一番障害が少ないところから始めている。

## 原典

`https://www.city.akishima.lg.jp/.../2-1.ippan.pdf`（469頁、4.0MB）。
市サイトの「令和7年度当初予算」ページに置かれており、**オープンデータカタログは存在しない**

事項別明細書は資料そのものが1会計ぶんで、会計名は表紙（p1）と目次（p2）にしか出ない。
`fund_label` として宣言し、どこを読んだかを `fund_basis` に書いてある。

## 組版（実測）

**1つの論理行が2頁にまたがる見開き**である。偶数頁が左、奇数頁が右。

| 頁 | 何が載るか |
|---|---|
| 左（偶数） | 款・項の見出し、目のコードと名称、本年度予算額、前年度予算額、比較、財源内訳 |
| 右（奇数） | 節の区分（コード・名称・金額）、説明欄 |

だから抽出器は2頁の文字を1つの座標系へ合わせてから行にまとめる
（`extract_statement.merge_spread`）。⚠️ **頁ごとに行へまとめてから突き合わせない** —
左頁で名称が2行に折り返し右頁は1行、という行数の食い違いが普通に起きるので、
行番号では対応が取れない。

⚠️ **列の x は direction で割れる。** 同じ資料の同じ団体でも、歳入の目の欄は名称が
折り返さない幅で組まれており（x 64〜300）、歳出は6文字で折り返す幅（x 64〜128）である。
片方の実測を両方へ当てると、歳出では目の名称が金額の欄へ、歳入では金額が欄外へこぼれる。

頁範囲は 20〜107 が歳入、108〜449 が歳出（450 頁から給与費明細書）。

## 説明欄

**direction で入れ子の作りが違う。これは法定様式の作りがそうなっている。**

| direction | 説明欄 | 節のコード |
|---|---|---|
| 歳出 | 事業 → 節 → 細節 の3段。節列は目の集計で、突合にしか使わない | **無い**（説明欄の中の節は名称だけ） |
| 歳入 | 節列の節の内訳が1段 | 有る（節の区分欄から取れる） |

配布物の1行は説明欄の**葉**である。3段は同じ金額を重複して印字しているので、
全部を行にすると合計が3倍になる。

⚠️ **説明欄を1行も持たない目がある。** 予備費（150,000 千円）は説明する内訳が無いので
説明欄が空で、葉が出ない。そのままだとその目の額が丸ごと消える
（実測で歳出計が 56,210,000 千円になり、歳入 56,360,000 千円と一致しなかった）。
目そのものを葉として残してある。

⚠️ **段は金額の右端 x が決める。名前の左端では決められない。**
名前は段ごとに字下げされるが、長い名前は下の段の字下げ位置を越えて右へ伸びる
（実測で細節の名前が x=458 まで来る）。金額は右揃えなので段ごとに右端が固定される（530 / 522 / 504）。

⚠️ **説明欄を名前と金額で固定の境界に割ってはいけない。** 名前が金額欄へこぼれる行が実在し、
実測（歳入 22-4-4 雑入）で「多摩・島しょ行政のデジタル化推進事業助成金（デジタル戦略担当）」の
末尾が境界に掛かって `）30,000` が数として読めず、**30,000 千円が黙って消えていた**。
いまは行末から右揃えの数字列を切り出している。

⚠️ **見出しは見開きごとに再掲される。** 款・項・目の見出しは継続の見開きでも印字されるので、
見出しを見るたびに文脈を畳むと継続した明細が行き場を失う。
実測で歳入の目「22-4-4 雑入」が 782,905 千円のうち 257,743 千円しか拾えていなかった。

⚠️ **科目の名称は次の行へ折り返す**（`社会福祉総` + `務費`）。しかも折返しが確定するのは
その目の最初の明細行より**後**である。名称を値でその場に写すと、
**その目の最初の1行だけが折返し前の名前を持つ**（実測 64 件。`保健体育総` と `保健体育総務費` が
同じ目に並んでいた）。抽出器は名札（可変の dict）を参照で持たせて最後に解決している。

## 突合（`bun run eval:extraction 132071`）

原典 CSV という外の正解が無いので、**資料が自分で印字している合計**を正解にしている。
同じ誤りが両側に入れば通るぶん、狛江市で回している recall より弱い。

| | 歳出 | 歳入 |
|---|---|---|
| 葉 | 3,588 行 | 423 行 |
| 目（見出し / 葉が付いた目） | 108 / 108 | 88 / 88 |
| 目の見出し金額と葉の合計の不一致 | 0 | 0 |
| 節列の合計と目の額の不一致（独立した経路） | 0 | 0 |
| 説明欄の段ごとの合計 | 3段とも 56,210,000 千円で一致 | — |
| 科目名称の欠け | 0 | 0 |

歳出・歳入とも合計 56,360,000 千円で、同じ予算書の総括（p14）の歳出合計と一致する。
⚠️ **同一資料の内部整合であって、外部資料による裏づけではない。**

⚠️ **説明欄には項目でない文字列が混じる。** 「(交付見込額)」「（措置対象者 25人）」や、
入所児童数の内訳表のような小表である。金額の右端が段に当たらないので落ちるが、
**歳入で 381 件、歳出で 7 件**を落としている（`annotationsDropped`）。
歳入で多いのは、交付金や負担金の積算根拠が説明欄に書かれる様式だからで、
落としているのは項目ではない — 目の合計と葉の合計が一致していることがその裏づけになる。

## 科目マスタへの対応

- 歳出は款1議会費〜款12公債費まで法定と同じ位置。**款13が予備費**で、
  法定の款13（諸支出金）を持たないため1つ詰まっている
- 款6の名称は「農林費」。法定は「農林水産業費」で、水産業を持たない市が落とした表記。
  項も農業費だけである
- 歳入は款10に国有提供施設等所在市町村助成交付金が挿入されるため、**以降が法定より1つ繰り下がる**
  （施行規則 別記の歳入の備考2による読み替え。`kind=addition`）
- 款8の自動車取得税交付金は2019年に廃止された旧法定区分（`kind=historical`）
- 表記差で対応表が要るもの: 市民税 / 市たばこ税 / 都負担金 / 都補助金 / 市預金利子 / 市債 /
  道路橋りょう費 / 公共施設災害復旧費

2024一般会計の歳入の物理頁29は二重文字層を除重した後の金額右端527.33を宣言し、節列を説明の先頭字から分離した。節4件から説明5行（1 / 51,000 / 15,914 / 141,000 / 544,000千円）を保持し、歳入は406行・90目・50,673,000千円で突合差0。今回追加された歳入表だけを新SHAで訂正し、既存106固定入力と原典PDFは変更しない。

## COFOG

3,588 行すべてに規則が当たっている（assigned 3,578 / out-of-scope 8 / unclassifiable 2）。
規則は `applies_to = 132071` で団体に閉じてある（**団体スコープの無い規則は、
名称が増えた瞬間に適用範囲が広がる**）。

⚠️ **衛生費は項の粒度で 07（保健）に寄せてある。** 昭島市の目には環境衛生費・環境費・
害虫等駆除対策費があり、内容としては COFOG 05（環境保護）に寄る。目まで降ろすのは
規則の分割という別の判断（既収録3団体の割当も同時に見直すことになる）なので、この版では降ろしていない。

⚠️ **幼稚園費は項ではなく目にある**（款10 項1 教育総務費の下）。他の3団体は項として
立っているので、団体をまたぐときに項の名前だけで探すと落ちる。
